# Conceptos Clave

Para usar Telegram Bot Manager efectivamente, es importante entender los conceptos clave y cómo todo encaja.

## Resumen

Telegram Bot Manager cierra la brecha entre la API estándar de bots y las capacidades completas de Telegram usando:

- **MTProto** - Protocolo nativo de Telegram
- **GramJS** - Implementación TypeScript de MTProto
- **Automatización de BotFather** - Interacción programática con @BotFather
- **TypeScript** - API type-safe con autocompletado completo

## Referencia Rápida

| Componente | Propósito | Usado Para |
|------------|-----------|------------|
| `BootstrapClient` | Conexión MTProto | Autenticación de usuario |
| `BotFatherManager` | Automatización de BotFather | Creación y config de bots |
| `GroupManager` | Gestión de grupos | Creación de supergrupo/foro |
| `TopicManager` | Gestión de topics | Creación de topics de foro |
| `EnvManager` | Gestión de entornos | Configuración multi-bot |
