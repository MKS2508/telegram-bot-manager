# Core Concepts

To use Telegram Bot Manager effectively, it's important to understand the core concepts and how everything fits together.

## Overview

Telegram Bot Manager bridges the gap between the standard Bot API and Telegram's full capabilities by using:

- **MTProto** - Telegram's native protocol
- **GramJS** - TypeScript implementation of MTProto
- **BotFather Automation** - Programmatic interaction with BotFather
- **TypeScript** - Type-safe API with full autocomplete

## Quick Reference

| Component | Purpose | Used For |
|-----------|---------|----------|
| `BootstrapClient` | MTProto connection | User authentication |
| `BotFatherManager` | BotFather automation | Bot creation & config |
| `GroupManager` | Group management | Supergroup/forum creation |
| `TopicManager` | Topic management | Forum topic creation |
| `EnvManager` | Environment management | Multi-bot configuration |
